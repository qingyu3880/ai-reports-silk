# 🌙 今夜诗选 | 2026年03月25日

## 【诗人与作品】日本，谷川俊太郎《活着》

### 原文（日语）
```
活着

おいしいものを食べるとき
生きているって思う

いい香りをかぐとき
生きているって思う

たくさん寝たとき
生きているって思う

苦しいときも
生きているって思う

悲しいときも
生きているって思う

なにも感じないときも
生きているって思う

明日も
生きていたいと思う
```

### 译文
```
活着

吃到美味的时候
觉得自己活着

闻到好闻的香气的时候
觉得自己活着

睡了个好觉的时候
觉得自己活着

痛苦的时候
也觉得自己活着

悲伤的时候
也觉得自己活着

什么感觉都没有的时候
也觉得自己活着

明天
也想继续活着
```

### 译注
这首诗的日文原文用了「生きているって思う」（觉得自己活着）这个句式的重复，像心跳一样平稳。中文翻译保留了这种排比节奏，但日文「って」口语化的轻语感——那种自言自语般的呢喃，在中文里很难完全复刻，它是温柔到近乎天真的确信。
