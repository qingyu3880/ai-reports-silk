# 全自动内容发布系统

## 触发条件

当用户或定时任务需要执行以下任一内容发布时：
- AI日报生成与发布
- 音乐推荐生成与发布
- 图书推荐生成与发布
- 电影推荐生成与发布
- 航空AI周报生成与发布

## 强制流程（必须严格执行）

```
生成内容 → 保存文件 → 推送到对话 → 同步网站 → 完成
   ↑___________________________________________|
   （任何一步失败，立即停止，禁止跳过）
```

## 执行前检查

1. 确定内容类型和日期
2. 检查目标目录是否已有当天文件
3. 如果已存在 → 读取并直接推送，跳过生成
4. 如果不存在 → 执行完整流程

## 强制步骤详解

### 步骤1：生成内容
- 使用子代理(sessions_spawn)生成内容
- 子任务必须包含：生成 + 保存 + 推送 + 同步 的完整指令
- 等待子任务完成

### 步骤2：保存文件（强制验证）
- 文件必须保存到指定路径
- 保存后立即读取验证文件存在且大小 > 1KB
- 验证失败 → 报错停止

### 步骤3：推送到对话（强制验证）
- 读取文件内容
- **使用 message 工具推送到当前对话**
- **禁止依赖子任务自我报告，主代理必须亲自验证**
- 推送后确认用户可见
- **禁止假设"同步网站=完成"，必须显式推送**

**关键修复：**
- 子任务完成 ≠ 内容已推送
- 子任务报告"已推送"可能是误判
- 主代理必须在子任务完成后，亲自读取文件并推送

### 步骤4：同步网站（强制验证）
- 运行 sync_reports.py
- 验证 reports.json 已更新
- 验证网站可访问（如配置）

## 内容类型配置

| 类型 | 生成时间 | 保存路径 | 字数要求 |
|------|---------|---------|---------|
| AI日报 | 9:00 | reports/ai-daily-YYYY-MM-DD.md | 1500-2000 |
| 音乐推荐 | 8:00 | recommendations/music/YYYY-MM-DD-曲目名.md | 800-1000 |
| 图书推荐 | 17:00 | recommendations/books/YYYY-MM-DD-书名.md | 1000-1500 |
| 电影推荐 | 20:00 | recommendations/movies/YYYY-MM-DD-片名.md | 1000-1500 |
| 航空周报 | 周一9:00 | reports/airline-ai/weekly-YYYY-MM-DD.md | 3000-5000 |

## 关键修复点（防止音乐推荐类错误）

### 错误模式识别
**问题：** 子任务报告"已推送"，但实际未到达对话
**原因：** 子代理可能将"同步网站"误判为"推送完成"
**后果：** 用户收不到内容，但系统认为已完成

### 修复方案
1. **子任务只负责：生成 + 保存 + 同步**
2. **主代理负责：读取文件 + 推送到对话**
3. **禁止子任务自我报告推送状态**

### 新流程图
```
定时任务触发
    ↓
主代理检查今天是否有文件
    ↓
如果没有 → 启动子任务（生成+保存+同步）
    ↓
子任务完成返回
    ↓
主代理读取生成的文件
    ↓
主代理推送到对话（使用message工具）
    ↓
完成
```

### 验证清单
- [ ] 子任务不包含"推送到对话"指令
- [ ] 子任务完成后，主代理必须读取文件
- [ ] 主代理必须使用message工具推送
- [ ] 推送后确认内容可见

- 任何步骤失败 → 立即停止
- 记录错误原因
- 不推送不完整内容
- 等待下次定时任务重试

## 用户确认

流程完成后，向用户报告：
- 内容类型和标题
- 文件保存路径
- 推送状态
- 同步状态
