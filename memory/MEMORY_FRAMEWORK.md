# 记忆分层管理框架
# 来源：用户指导 - 2026-03-07
# 目的：解决记忆混乱问题

## 第一层：记忆分层

| 类别 | 存放位置 | 例子 |
|------|---------|------|
| 长期稳定偏好 | 全局记忆 (MEMORY.md) | 输出风格、常用语言、格式偏好 |
| 项目长期信息 | 项目记忆 (memory/projects/) | 项目目标、关键约束、核心术语 |
| 短期待办 | 任务/日历 | 下周提交、明天提醒、月底回访 |
| 即时讨论内容 | 当前会话 | 这次要写的文案、当前分析问题 |

**核心原则：不要让一个系统同时扮演大脑、便签、日历、CRM、项目文档**

## 第二层：记忆写入规则

1. **只有明确确认的信息才能进入长期记忆**
2. **临时讨论内容默认不写入**
3. **角色扮演内容禁止写入本人记忆**
4. **项目信息必须归属到对应项目空间**
5. **发生冲突时，优先使用最近一次确认版本**

## 第三层：我的应用

### 全局记忆 (MEMORY.md)
- 用户基本信息（高管、54岁、航空公司）
- 偏好（书法、话剧、高尔夫）
- 沟通风格偏好
- 技能清单（VERIFIED_SKILLS.md）

### 项目记忆 (memory/)
- 每个项目独立文件
- 技能安装项目 → memory/skills-setup.md
- 日报项目 → memory/daily-reports.md

### 短期/待办
- HEARTBEAT.md 每日检查
- cron 定时任务

### 当前会话
- 即时讨论，不写入长期记忆
- 本轮对话内容

## 执行检查

写入MEMORY.md前问自己：
- [ ] 这是长期稳定偏好吗？
- [ ] 用户明确确认了吗？
- [ ] 不是临时讨论吧？
- [ ] 不是角色扮演内容吧？
- [ ] 归属正确吗？

只有全部"是"才写入 MEMORY.md
